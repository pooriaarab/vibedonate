# vibedonate

BitTorrent-style mesh for AI inference — donate spare capacity (idle subscription hours, API credits, local compute) across Claude, Codex, Gemini, Grok, pi. Your hardware, opt-in, metered.

Part of the **Vibe Suite** — companion tools for agentic coding CLIs (Claude Code, Codex, Gemini, Grok/pi, Kimi). Ships as **CLI + npm package + MCP server**.

**Local-first: runs on your own machine, no data out** (consent model in `@vibe/core`).

## Prototype
Interactive, self-contained UX prototype (no build, no network): open [`docs/prototype.html`](docs/prototype.html) in a browser.
